# Vestigia 2831 p.4 (Buda 22 Nov 1489) - last page, reading from stacked unboxed crops, lines 1-17

L01: quello che sapia et possi co[r]e[?] (ca-r-e / co-r-e; sense wants "fare"). Sed hoc non fallet divinam sapientiam
 signs: ) . s // n^e e-eps | s 9 // | m^a c n r | r-stroked (et) | c e-eps n+ n | b-crossed 3/z // | [CLEAR LATIN: Sed hoc non fallet divinam] | m^a c n // g o-bar n r a
   (quello = ) . s // n^e eps, n^e = ll, epsilon = o; che = s 9 //; sapia = m^a c n r; et = the r-stroked ligature; possi = c eps n+ n;
    then the tall crossed-b sign + r + e: the SAME sign reads "co" in L02 "ancora", so "core"/"care" - the sense wants "fare", unresolved [?];
    the clear Latin "Sed hoc non fallet divinam" is written in the plain hand, then the last word goes back into cipher:
    m^a c n // g o-bar n r a = sa-p-i-e-n-t-i-a-m "sapientiam", matching the accusative "divinam" - so the sentence is
    "Sed hoc non fallet divinam sapientiam", the compliment to Ludovico that closes the ciphered part.)

L02: de la. Ma[?] se e dicto ancora che la co-m-u-n-d-a-co-a[?] ... non[?] i colo[?] (colui?) iuncho[?] al Soldano /
 signs: x // d r | a-f (ma? or the et-ligature) | m^e | // x n s o-bar 3 | r g b-crossed q^a | s 9 // | d r | 6/b a v g x r b-crossed i | 8 e-eps g | n b-crossed d 3 | n 6 g s 9 e-eps | r d | d e-eps d x r b^o | / (line-end flourish/null)
   (SECURE: "x // d r" = de la; m^e = se; "// x n s o-bar 3" = e dicto (x n s o-bar 3 = dicto, exactly as p.1 L29);
    "r g b q^a" = a-n-co-ra ANCORA - this fixes the tall crossed-b sign as "co"; "s 9 // d r" = che la;
    "n 6 g s 9 e" = i-u-n-c-h-o "iuncho" (= iuncto/giunto?); "r d" = al; "d e-eps d x r b^o" = s-o-l-d-a-no SOLDANO.
    So the ciphered part ends "... che la ... al Soldano" - the Sultan.
    UNREAD: the long group after "che la" = co/u-m-n/u-n-d-a-co-a (looks like "comanda-", but no Italian word fits the tail);
    and "8 e g | n b d 3" = n-o-n + i-co-l-o, perhaps "non ... colui". The a-f sign at the start is either the et-ligature
    or a(m)+f(a) = "ma"; "ma se e dicto ancora" reads better than "et se e dicto ancora".)

WHERE THE CIPHER STOPS: the ciphered text runs to the end of L02 and no further. The last ciphered
words are "... al Soldano", followed by the line-end flourish. L03 ("Credo che la Ex.tia Vostra
havera facto dar quelli ducento ad m. Francesco ...") down to the date and signature is all in the
clear, and it is a private postscript about the writer's own money: his 200 ducats, the 150+ ducats
of his own he has spent at Buda, and the plea to be included among the other Chancellery clerks
"in lassignatione facta ad la Cancellaria" - the explicit given in the archive description (L14-L15).
Inside the cipher, L01 has a whole clear Latin clause ("Sed hoc non fallet divinam ...") with only
the last word, "sapientiam", put back into cipher.
