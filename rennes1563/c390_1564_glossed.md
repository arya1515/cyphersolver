## How the glosses work
The margin gloss is a condensed running decipherment, NOT line-for-line: it starts at the top of the margin
(beside clear text) and runs down, so it can sit several lines above the cipher it renders, and it drops
function words. Matching is by words.

## Result for the blocking list after this pass

- ℛ: one instance, p.347 block 1 l.1 (unglossed): open.
