# R4734: endorsement (IMG_R4734_I27761_P3)

## Summary

Chancery endorsement on the outer leaf: a **copy of a letter from the Imperial Vice-Chancellor (Reichsvizekanzler,
i.e. Ferdinand Sigismund Kurz von Senftenau himself) to Count [von] Schwarzenberg** (presumably Adam von
Schwarzenberg, the Brandenburg minister), dispatched **8 April 1639**. Letter "A" of a series. The tr/ file read
the addressee as "Herrn Kurzen von Senftenau(?)"; the image reads "Herrn Graven [?] von Schwartzen-berg". Same
endorsing hand as R4645 P4. Nothing illegible; one word doubtful.

Conventions: line breaks as in the MS; abbreviations as written; [?] = doubtful.
