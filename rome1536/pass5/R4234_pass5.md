# R4234 pass 5: shape-true re-transcription from the Gallica native scans

Record: DECODE R4234, Mâcon to Montmorency, Rome, February 1536 (o.s. = 1537), BnF fr. 3053 ff. 16r-18v.
Images: Gallica ark btv1b90601432, native scans saved in `work_shape/gallica/` (f16r = view 32, f16v = 33, f17r = 34,
f17v = 35, f18r = 36, f18bis = 37, f18v = 38; map in `gallica_views.md`). DECODE crops P2/P3 = f16r, P5/P6 = f16v,
P8/P9 = f17r, P11/P12 = f17v, P16/P17 = f18r, P19/P20 = f18v; P15 = f. 18bis, the clear copy of f. 18r.

Method: line baselines fitted per page (8 vertical strips, peak tracking, quadratic fit, `seg.py`/`clean.py`), each
line straightened and cut into three overlapping segments at native resolution (`rend.py`), transcribed sign by sign
with the catalogue IDs, then direct key map + 5-gram LM beam (`shapedec.py` functions, `fr-1600-letters`), then
lexicon word division. Working files: scratchpad `r4234/` (t16r/t16v/t17r/t17v/t18r/t18v.txt = transcriptions,
rows.json = all outputs).
The f18r lines that the pilot already transcribed (P16 L4-L14, L19-L20) and the f18v pilot lines (P19 C1/C2/C5/C6,
P20 C7/C8) were NOT re-transcribed: I checked their rows on the Gallica native (they match) and reused the pilot
signs. Everything else (145 of 164 line units) is new, transcribed blind of the old line readings. The old readings
were not consulted line by line during transcription (only the overall P2 opening had been seen before starting).

`milan`/`Millan`, `lion`/`Lyon`, `pase`/`passé`) and one struck-through sign in `corruptible`.

Line units: 164 (150 of 20+ letters, 14 short cipher runs inside clear lines), 5,369 cipher letters.

## New sign IDs / values found on these leaves (see `catalogue_additions.md`)
- `FF` stemmed triangle (Δ with a descender) = FF: `affaire` (f16r L5, L17), `offices` (L26).
- `ʀ` low wavy X-like stroke = null in most places (`l'autre`, `ung gentilhomme`, `avec Cosme`, `se ourdissoit`,
  `le dict`), but X in `lieux`, `deux`, `imperiaulx`: treat as {nE|X}.
- `M1` single stroke read as the second M: `q 1 o` = MME in `gentilhomme`, `somme`, `comme`, `hommes`.
- `ƀ` (ring with cross) stands for S/SS as well as E: `dessusdictz`, `au cas`, `confession`, `assignation`,
  `necessaire`, `messire`, `s'ourdissoit`.
- `Nx` (curly x) vs `Tx` (curly saltire with loop): both occur; Nx = N in `ennemi`, `entendu`, `moiennant`,
  `sinon`, `a Venise`; Tx = T in `toute`, `estoit`, `feroient`.
- hooked `ʃh` = Q in `quelque`, `cinq`; `∂` (8 with a hook) = H in `chose`, `Jehan`, `cheual`, `prochain`.
- `ʓ` (3 with a tail) = Z in `propoz`, `dictz`, `filz`, `soubz`; `O2` (a 2-shape) = O in `possible`, `vouloir`.

  Sienese gentleman's name `For[?]`, L21 `con[d]loi[e]`, L23 `[?] coing de l[a]`, L27 `our[i]ime` (opprimé?), L30-L31;
  f17v L14 the name read `parulan`, L20 `la isgo ou[lup]allier`; f18r L15-L17 (`ne ... pa`, `le cas autce`).
