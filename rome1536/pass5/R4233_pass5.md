# R4233 pass 5 - shape-true re-transcription (BnF fr. 3053, f. 6 ff.)

Mâcon to Montmorency, Rome, 26 January 1536 (o.s. = 1537). Signed "Car^al de Mascon" (P26).
Images: DECODE crops `IMG_R4233_I25177_P<n>.jpg` (2,400-3,400 px wide, fully legible), cut into line tiles with
autocontrast (scratchpad `t*.png`, `s33/`). Gallica views for ff. 6-10 were not fetched: the DECODE crops are legible
throughout the cipher passages.
Decoder: `shapedec.py` key map + 5-gram beam (`fr-1600-letters`) through scratchpad `dec.py`; transcription files
scratchpad `t4233.txt` (passages 1-2), `t4233b.txt` (3), `t4233c.txt` (4), `t4233d.txt` (5), `t4233e.txt` (6-7),
`t4233f.txt` (8-9). Signs use the catalogue IDs; `{Of|Up|Pn}` marks the ǂ family where the bar/loop could not be
settled at tile scale (the beam chooses). The old reading (origin/main `rome1536/R4233.md`) was read before this
pass, for passage boundaries; each line was transcribed from the image before its old reading was compared.

Letter-specific values seen here: 7 = B in "bon", "bailler", "possible", "agreable", "bonhomme", "bien"; б (Eb) = E,
SS and H ("messieurs", "dessaing", "bonhomme", "homme"); `S` (the 5-stroke) = D, but G in "garson", "congnoisant",
"agreable", "grant"; ꭓ = N, T, U and X ("ceulx"); `10` after ǂ = the single M-stroke (M1) in "bonhomme", "homme"; ʃʃ
(the tall hairpin) = P; ω = S and PP ("d'oppinion"); + once = C in "secretaire".
