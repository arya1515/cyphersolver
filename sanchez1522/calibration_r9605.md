# R9605 as calibration: cipher and contemporary decipherment on facing leaves

DECODE R9605, RAH Salazar 9/24 f. 39–44, Sánchez to Charles V, Venice, **7 May 1522**.
This is the record Tomokiyo broke the cipher from. Images fetched 2026-09-20.

- `IMG_R9605_I45170_P2.jpg` — left leaf (f. 44) the **last seven lines of the cipher**, right leaf
  (f. 42) the **contemporary decipherment in clear**, headed *Al Rey / De Alonso Sanchez de Venecia
  de vij de mayo 1522*.
- `IMG_R9605_I45176_P2.jpg` — left leaf the **end of that decipherment**, right leaf a full page of
  cipher belonging to the next letter.

So the letter exists in cipher and in a full clerk's plaintext, on facing pages. That is the ground
truth this hand can be calibrated against.

## The alignment at the end of the letter

Decipherment (f., last lines, read from the image):

> … Despues que recebi la de V. Mag[esta]d, que fue a xxv, en fin me mando a mi ser de la venida del
> visorey con todas las postas, que despacho y escrivo y he venido; y lo mesmo hago … de todo aviso.
> **Plegue a Dios no lo yerre en el camino.** De Venecia a vij de mayo 1522.

Cipher (f. 44, last two lines; the words in *italics* stand in the clear on the page itself):

> … *plegue adios* `nuf` `pac` `ɡɣβ4q4` `vog` `veg` `zn·β·aɥ` `nuf` ‖‖‖ *en Venecia a vij de mayo 1522*

Term by term:

| cipher | plaintext | how |
|---|---|---|
| `nuf` | no | code |
| `pac` | lo | code |
| `ɡɣβ4q4` | yerre | spelled |
| `vog` `veg` | **en el** | code — Tomokiyo's own way in |
| `zn·β·aɥ` + `nuf` | **cami** + **no** = *camino* | spelled, then the code `nuf` (no) used for the last syllable |

Two things this settles that could not be settled from the key alone.

1. **Code groups are used for syllables, not only for words.** `nuf` is *no* the adverb in one breath
   and the final syllable of *camino* in the next. Any reading that assumes a code group is always a
   whole word will mis-segment.
2. **The lookalike signs separate.** In `zn·β·aɥ nuf` = *camino* the third sign is `β` = **m**; in
   `nx#Ɋn` = *ahora* (R9635 f. 20r) the fourth is `Ɋ` = **r**. Both are easy to write down as a
   "g"-shape at DECODE's resolution, and they are the single largest source of error in reading the
   spelled runs. The bold `∞` (letter g) is a third member of the same confusion set.

## Why this does not amount to reading the group

R9605 and R9613 are already deciphered — by the Emperor's own clerk in 1522, on the facing leaves.
Transcribing that clear text produces a continuous plaintext of those letters, but it is an edition of
a 1522 decipherment, not a decipherment. The records that are genuinely unread (R9635, R9653 and the
rest of the 9/26 tail) have no such facing plaintext, and reading them continuously means resolving
`β` / `Ɋ` / bold `∞` at every occurrence by eye.

The calibration route is now open and is the next session's work: run the same alignment across the
whole of R9605's cipher and its decipherment — several hundred signs of ground truth — to fix each
homophone's shape in this scribe's hand, then apply that to the unglossed pages.

## The alignment continued: three more results

The same passage, a few words earlier. Decipherment: *"… la venida del visorey **con todas las
postas**, que despacho y escrivo y he venido; y lo mesmo hago …"*. Cipher (f. 44 ll. 5–7):

> `ded` `xof` `xel` `def` *con todas las postas* `vog` `ho` `va` `gd` `t·a·z·ɡ·aɥ·m·#` … `pog` `suf` …

1. **`xel def` = *del visorey*, `ded xof` = *veni*+*da* = *venida*.** Verbatim against the clear, and
   another instance of code groups carrying syllables rather than words.
2. **`va` = *despacho*, not "desponho".** Tomokiyo's table has `va` = *desponho*, a word that is not
   Spanish; the clear here reads *que despacho y escrivo*, with `ho` = *que* and `va` in exactly that
   slot. This also explains his puzzled "me desponho x-e-r-o-n que" in R9623. **A correction to the
   published key.**
3. **Seven signs for seven letters in *escrivo*.** The spelled run after `gd` (= the conjunction *y*)
   is `t·a·z·ɡ·aɥ·m·#` against plaintext e-s-c-r-i-v-o, which fixes, with ground truth beneath it:
   `z` = c, `ɡ` = r, `aɥ` = i, `m` = **v** (the u/v sign), `#` = o, and the first two signs as e and s.
   That is the method working: the clear tells you which homophone you are looking at.

Also aligned, with `pog` = *mesmo* and `suf` = *hago* in *"y lo mesmo hago"*.

## One check that came out inconclusive

The clear at *"Despues que recebi la de V. Mag[esta]d que fue a …"* carries the cipher group `cud`,
which Tomokiyo reads "xxiv?" with a query. If the clear read *xxv* there, the whole c-block numeral
series would shift by one and the values predicted here would be wrong. It does not settle it: the
date in the decipherment is written over a correction and reads as something like *xxv y xxvij*, two
dates rather than one, so it cannot be matched to the single group `cud`. **Left open.**

The values `cab` = xv, `cef` = xxvi and `cif` = xxvii do not depend on this: they were each confirmed
in their own context (*mas de xv mil ducados*; *cartas de Francia de xxvi y xxvii del passado*, two
consecutive days), independently of where the run starts.

## The opening of R9605, read straight through against the clear

f. 39r is the first cipher page; f. 42 the first page of the clerk's decipherment. The two align from
the first word. Decipherment:

> *Ya dixe a V. Mag. que el embaxador de Hungria fue respondido de los desta republica con buenas
> palabras…*

Cipher, f. 39r ll. 1–2 (`‖` a null, *italic* = written in the clear on the page):

```
‖ como ‖ quien ‖ | cig | vu·o·ɣ | n | dom pud | ho | veg | vam vuc·ɡ | xig | n·℔·∞
ɡ·aɥ | sa | ɡ·ɣ·q·ao·#·& vu vuc | xig | pac+s | xig vum | ɡ·ɣ lal | xa | yuc·n+s
```

Term by term, with the clear underneath at every point:

| cipher | plaintext | how |
|---|---|---|
| `cig` | **ya** | code |
| `vu`·o·ɣ | **di**+x+e = *dixe* | code `vu` (di), then the signs for x and e |
| `n` | a | letter |
| `dom pud` | vuestra magestad | code |
| `ho` `veg` | que el | code |
| `vam` `vuc`·ɡ | **embaxa**+**do**+r = *embaxador* | two codes, then the sign for r |
| `xig` | de | code |
| `n·℔·∞` `ɡ·aɥ` | Hun-gria | spelled across the line break |
| `sa` | **fue** | code |
| `ɡ·ɣ·q·ao·#·&` `vu` `vuc` | r-e-s-p-o-n + **di** + **do** = *respondido* | spelled, then two codes |
| `pac`+s | los | code |
| `xig vum` | de esta | code |
| `ɡ·ɣ` `lal` | r-e + **publica** = *republica* | spelled, then code |
| `xa` | con | code |
| `yuc`·n+s | **buen**+a+s = *buenas* | code, then two signs |

Nothing here is a guess: every group has the clerk's own plaintext standing over it on the facing leaf.

| `q` | s | *re**s**pondido* |

Note `q` = s here against `q` = t in Tomokiyo's alphabet column: two similar glyphs, and this is the
pair to watch next.

## What this does and does not amount to

It calibrates the hand, and it shows the method reading continuously — but on a letter the Emperor's
clerk had already deciphered in 1522. **Reading R9605 is not a new reading.** Its value is that the
sign table above, every value of it resting on ground truth rather than on eye, is what the genuinely
unread pages of the 9/26 tail need. Carrying it across to R9635 f. 20r and the rest is the next step,
and it is now a mechanical one rather than a matter of judgement.
