# Working key — AGS Estado 8/150 (governors' cipher, Vitoria 30 Dec 1521)

System: three-letter code groups (words, and also syllables inside words) + a homophonic letter
alphabet of signs, letters and figures. Code groups take sign endings for grammatical forms
(mix = la, mix= = las; fom = cosa, fom= = cosas; dop+ca+s = urcas). Paragraphs open with `≠ P4`
and close with `P4 ≠` (markers/nulls).
