# R1101 emperor-expression recurrence check

20 September 2026. Status: in progress.

Q08 in `r1101_queen_parallel.md` contains an expression aligned with 7a's
reference to the emperor, but its spelling/encoding is unresolved. A closer
view is `img/r1101_emperor_expression.png`, source I5654 rectangle
`(800,1080,1110,1170)`. Its ordinary-looking letter forms are not enough
to call it an established nomenclator entry.

`search_emperor_r1101.py` uses the same three-scale local-contrast retrieval
method as the earlier K search. Its tighter template is `(940,1100,1100,1160)`
in I5654; searched sources are I5654's established writing regions and the
first original page, Vestigia 1284 photograph `(103)`, region
`(1200,180,3330,2850)`. Scripts and candidate scores are preserved.

The original template was recovered at score 1.0, confirming the search
coordinates. Visual inspection of the 18 retained candidates for each image
did not establish a second full-expression match. I5654 candidate 3,
`(740,1508,868,1556)`, score 0.5451, was additionally inspected in wider
context (`img/emperor_candidate3_context.png`); it is a fragment of ordinary
prose, with no verified equivalence to the target expression. Other hits
primarily share generic letter strokes.

No emperor code entry or original-word expansion is accepted. The negative
retrieval does not prove absence: spacing, scale and handwriting variation
limit matching. The remaining useful route is direct collation of other
7a emperor passages, rather than treating these image scores as readings.
The original Q08 gap remains, while the witness correspondence is retained.
