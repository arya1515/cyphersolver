# Sign vocabulary for keys9423

ASCII codes used in the block files. Plain letters/digits (A, V, 3, 8, m, w, q ...) stand for themselves.
Greek-letter names stand for the Greek shape. A trailing `~` = hooked/looped/curled variant; `-` or `=` = one or two
added bars; `o` suffix = the sign stands on / ends in a small ring; `'` = mirrored/reversed; `.` = with a dot;
`?` = doubtful reading. When a block file gives a parenthesised description, that description governs.
