## Assessment

- Cipher letters: about 1,150 letter signs plus 60 code groups. Read confidently: ~93% of letter signs; doubtful
  spans: l.2 end (le/les + 2 signs), l.3 *quelqu'on* (h/ʃ as q), l.4 start (*a…lles si*), l.5 start (*donno(r)it a (u)n*),
  l.6 start (smudged, *second?*), l.20 end (*au…*), v10 (*d'entre…mant*).
- Corrections to reading11.md: *la regence de l'estat* (not "la regaigner de les…"); *subjects qui pourront estre
  proposés* (no "s'y"); *la charge et administration* (ℓℓf = et); [106] = *non* ("toutte non pas difficulté mais
  impossibilité"); *quatre millions* (not "qu'a[ultre]"); *promettant d'espouser sa fille* (not "possessions"); *vouldra
  desmander*; *en ce [250] qui sont*; *d'entre…mant*.
- Codes open, with context:
  - 305: "rentrant en opinion de [305] la couronne pour luy" — *retenir*/*prendre*/*avoir*.
  - 283: "par [283] de Rome" — *lettres* fits.
  - 130: "si pouvant [130] la couronne pour luy, il la donneroit a un aultre" — *avoir*/*retenir* (same slot as 305?).
  - 250: three uses — "le Roy d'Espaigne luy [250] presenter quatre millions", "le cardinal de Bourbon le [250]
    rechercher", "en ce [250] qui sont" — a verb like *doit/veut/peut* fits the first two; the key's "tout" fits none
    well; "en ce [250]" might be *temps*/*conseil*. Treat 250 ≠ tout here, open.
  - 297: "avec luy les [297] principaulx qui suivent le party du Roy de Navarre" — *plus*/*catholiques*.
  - 64, 50: "qui sont [64] de [50], Villeroy" — Mayenne's secret council was Jeannin, Villeroy and Pierre d'Épinac,
    so 64 = *l'archevesque*, 50 = *Lyon* (historical inference, strong).
  - 235 = président (confirmed: "le [235] Jannin").
- Key notes: ꝛe also serves for r (3H-like) in *estre*, *rentrant*; → used for g in *regence*; h (long) = l in
  *resolution, election, Villeroy, solliciter, fillie*; δ̂ (δ with cross) = i in *millions, solliciter, troisiesme*;
  ✱ once for r (*voi(r)oit*); 3f for q in *que* (v6); barred ƒ = b in *Bourbon*; nulls X, 4+, o-f precede cipher runs
  and code groups throughout.
