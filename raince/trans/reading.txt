# Raince, BnF fr. 2984: the reading of the ciphered residue

Each line is given twice: `H` = read glyph by glyph off the microfilm against the
measured key, one character per segmented token (gold/labels.txt); `M` = the machine
decode (classifier + period-French 6-gram beam, draft9.txt) for lines not yet read by
hand, which is right on about 85-90 % of letters and is NOT a reading. `?` = a token
that did not resolve; word spacing is supplied by a lexicon segmenter and is a reading
aid, not evidence. Lines run on: a word broken at a line end continues on the next.
